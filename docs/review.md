## Границы учебного проекта

Это однопользовательская учебная ИС без регистрации и разграничения ролей. В публичной демонстрации используются только тестовые данные. SQLite в Docker хранится в постоянном томе; Community Cloud может сбросить локальные данные после перезапуска. Для дальнейших недель можно добавить авторизацию, PostgreSQL и отдельное постоянное размещение Backend.

## Среда разработки

Код подготовлен с помощью Codex; VS Code установлен. Нажатие Apply в Cursor и подключение Copilot не выдаются за выполненные действия. Основные этапы сохранены отдельными коммитами с фактическими датами выполнения.
